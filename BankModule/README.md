## 🚀 Quick Start

### 1. Install Dependencies

```bash
cd support-module
npm install
```

### 2. Setup Environment

Create `.env.local`:
```
VITE_API_URL=http://localhost:5000/api/support
```

### 3. Run Development Server

```bash
npm run dev
```

Navigate to: **http://localhost:3002**
